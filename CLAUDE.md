# CLAUDE.md — карта проекта plan350

**Проект:** генератор бизнес-планов под господдержку (соцконтракт, гранты МСП, документы
на регистрацию ИП). Рабочее название папки — `plan350` (по сумме 350 000 ₽), бренд и домен
не выбраны, решить перед запуском рекламы.

Полное обоснование ниши, экономика, конкуренты, этическая рамка — в `plans/2026-08-31-generator-biznes-planov.md`.

> Владелец — не новичок в коде, но не эксперт в этой предметной области (соцзащита,
> господдержка). Объяснять юридические/региональные нюансы, а не только код.

## Карта папок

| Папка | Что внутри |
|---|---|
| `plans/` | Планы на каждую функцию (по одному файлу на задачу), как в соседних проектах. |
| `src/app/` | Страницы и API-роуты Next.js: лендинг, анкета, чекаут, вебхук, выдача заказа. |
| `src/lib/` | Ядро: региональная база, промпт-конструктор, оркестрация генерации, ЮKassa, почта. |
| `src/pdf/` | React-PDF шаблон бизнес-плана + шрифты. |
| `src/components/` | UI-компоненты сайта и форма анкеты. |
| `prisma/` | Схема БД — модель `Order` (анкета + платёж + статус + готовые файлы). |
| `dev-tools/` | Дев-скрипты вне сборки сайта: рендер образца PDF, инспектор PDF для отладки вёрстки. |
| `samples/` | Образцы сгенерированных планов — для ручной вычитки перед подключением трафика. |

Сайт собирается и проходит `pnpm run build` / `pnpm run lint` без ошибок (проверено
2026-09-01). Что нужно от владельца для реального запуска — `plans/zapusk-chek-list.md`.

## Стек

- **Next.js 16 + Prisma + pnpm**, как в `../My project` (muzmagic) — checkout и вебхук
  ЮKassa, PDF-генератор (`@react-pdf/renderer`), Resend-рассылка перенесены оттуда.
- **ChadGPT** (`ask.chadgpt.ru`, модель `claude-5-sonnet`, OpenAI-совместимый API) —
  генерация текста плана через `src/lib/generate.ts`, структурированный вывод через tool
  calling. Не напрямую Anthropic API — с российских карт нельзя пополнить
  console.anthropic.com; ChadGPT — российский сервис, оплата рублями (решение от
  2026-09-06). Цифры сметы AI не придумывает — только берёт из анкеты (см. правило
  источника цифр в `src/lib/plan-template.ts`).
- **ExcelJS** — смета отдельным файлом для тарифов «Стандарт»/«Максимум».

## Обязательные правила работы

### 1. Сначала план в `plans/` — на каждую новую функцию
Как в остальных проектах: план → согласование с владельцем → код.

### 2. Этическая рамка — не обсуждается
Клиенты — люди с доходом ниже прожиточного минимума. Никаких «гарантий одобрения»,
никаких выдуманных цифр в документах, честное упоминание бесплатной альтернативы
(центры «Мой бизнес»). Подробности — в основном плане.

### 3. Региональные факты — только проверенные
**Соцконтракт на открытие бизнеса не действует в Москве** (проверено несколькими
источниками, 2026-08-31). Не таргетировать рекламу на Москву по этому офферу,
явно писать об этом на сайте. Точная сумма выплаты варьируется по регионам —
не выдумывать цифры там, где не проверено; помечать как «уточнить» в `lib/regions.ts`.

### 4. В конце сессии — короткая рефлексия
Что сделали, что осталось, на что обратить внимание.
