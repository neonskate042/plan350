# Чек-лист запуска — что нужно от владельца

Обновлено: 2026-09-01. Сайт, анкета, приём оплаты, генерация плана и выдача —
весь код готов и собирается без ошибок. Ниже — только то, где нужны твои
данные, деньги или решение.

---

## 1. Домен и бренд (решить в первую очередь)
Сейчас сайт называется «План350» — рабочее имя (по сумме 350 000 ₽), домен не
куплен. Нужно решить:
- [ ] Устраивает ли имя «План350» / plan350.ru, или придумать другое
- [ ] Купить домен

Пока домена нет, весь чек-лист ниже можно проходить с `SITE_URL=http://localhost:3000`
или временным поддоменом хостинга — заменим на боевой домен перед запуском рекламы.

## 2. ChadGPT (доступ к Claude) — без этого генерация не работает (главный блокер)
Российские карты не работают с console.anthropic.com напрямую, поэтому генерация
идёт через ChadGPT — российский сервис, оплата рублями, у тебя там уже есть
оплаченный аккаунт (решение от 2026-09-06). Сайт принимает анкету и оплату без
этого ключа, но не может собрать документ — клиент оплатит и получит письмо об
ошибке вместо плана.
- [ ] Проверить, что баланса/тарифа на chadgpt.ru хватает на API (не только на
      обычный чат-интерфейс — иногда это разные лимиты)
- [ ] Личный кабинет → раздел API → создать/скопировать API-ключ
- [ ] Прислать ключ — вставим в `CHADGPT_API_KEY`. Модель уже прописана в коде
      (`claude-5-sonnet`, сверено по их документации) — трогать не нужно.

## 3. ЮKassa — приём денег (новый магазин, не тот, что у muzmagic)
Это отдельный сайт с отдельным юрлицом-магазином в ЮKassa (тот же ИП, но
отдельная точка приёма платежей — так проще разделять бухгалтерию по продуктам).
- [ ] Подать заявку на подключение (ИП, новый сайт, услуги/цифровой продукт)
- [ ] Сказать систему налогообложения — от неё зависит НДС в чеке (уже стоит
      код «1 — без НДС», это для УСН/патента)
- [ ] Прислать тестовые и боевые `shopId` + `secretKey`
- [ ] В кабинете: Интеграция → HTTP-уведомления →
      `https://<домен>/api/payments/yookassa/webhook`, событие `payment.succeeded`

## 4. База данных Neon
- [ ] Создать новую базу в Neon (отдельную от muzmagic — свой продукт, своя база)
- [ ] Прислать строку подключения → `DATABASE_URL`
- [ ] После этого один раз выполнить `pnpm prisma migrate deploy` (сделаем вместе)

## 5. Resend — отправка писем
- [ ] Либо использовать тот же аккаунт Resend, что у muzmagic (добавить новый
      домен для отправки), либо завести отдельный — на твой выбор
- [ ] Подтвердить домен отправки, прислать `RESEND_API_KEY` и `EMAIL_FROM`
- [ ] До подтверждения домена можно временно слать с `onboarding@resend.dev`

## 6. Переменные на сервере
Когда домен и хостинг выбраны — панель хостинга → приложение → переменные
окружения. Полный список — в `.env.example`, коротко:

```
DATABASE_URL, RESEND_API_KEY, EMAIL_FROM, AUTH_SECRET,
CHADGPT_API_KEY, CHADGPT_MODEL, YOOKASSA_SHOP_ID, YOOKASSA_SECRET_KEY,
YOOKASSA_VAT_CODE, SITE_URL, NEXT_PUBLIC_METRIKA_ID
```

`AUTH_SECRET` — любая случайная строка, сгенерирую сам.

## 7. Хостинг и деплой
- [ ] Где разворачиваем — тот же Timeweb, что и muzmagic, или другой хостинг
- [ ] Отдельное приложение (не в той же папке/поддомене, что muzmagic)

## 8. Яндекс.Метрика
- [ ] Создать новый счётчик на metrika.yandex.ru для нового домена
- [ ] Цели: `checkout_start` (нажал «Оплатить» в анкете), `purchase`
      (аналогично countract muzmagic — сделаем вместе, когда домен будет готов)

## 9. Прежде чем включать рекламу — обязательная проверка
- [ ] Сгенерировать 2–3 тестовых плана через реальную анкету (тестовый режим
      ЮKassa) и вычитать их — соответствуют ли требованиям, нет ли повторов,
      адекватна ли финмодель. Без этого шага трафик не включаем — так
      договаривались в основном плане.
